Optional để xử lý giá trị có thể null một cách tường minh, tránh NullPointerException, và các anti-pattern khi dùng sai.

## Nội dung sẽ bao gồm

- Vấn đề null & NPE
- Tạo Optional: of / ofNullable / empty
- map / flatMap / filter
- orElse / orElseGet / orElseThrow
- Anti-patterns (Optional cho field, parameter)
