## Tổng quan

Bốn tính chất nền tảng của lập trình hướng đối tượng trong Java: Encapsulation, Inheritance, Polymorphism, Abstraction.

## Nội dung sẽ bao gồm

- Encapsulation — đóng gói dữ liệu, getter/setter
- Inheritance — kế thừa, tái sử dụng code
- Polymorphism — overriding vs overloading
- Abstraction — abstract class vs interface
- So sánh & khi nào dùng cái nào
